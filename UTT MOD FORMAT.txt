ULTIMATE TIC-TAC-TOE (UTT) - AI MOD FORMAT
==========================================

PURPOSE
Write a single Python file that adds a custom AI opponent to the game
"UTT_2.py" (Tkinter Ultimate Tic-Tac-Toe). The file is dropped into a "Mods"
folder and the AI then appears in the game's difficulty menus.


1. REQUIRED FILE FORMAT
-----------------------
- One plain .py file. Python standard library only (no third-party packages).
- It must define a top-level function:

      def choose_move(game):
          ...
          return (board, cell)

- It may define a top-level string:

      AI_NAME = "MyAI"

  If AI_NAME is missing, the file name (without .py) is used.
  The name is cut to 32 characters. Use a unique name. Do NOT reuse a built-in
  name (Easy, Medium, Hard, Nightmare, Oracle, Katrina2): a mod with that name
  would override the built-in AI.
- File names starting with "_" are ignored by the loader.
- The mod must not import the main game script. Make it self-contained.


2. HOW IT IS LOADED
-------------------
- The game looks for a folder named "Mods" next to UTT_2.py (created
  automatically if missing) and loads every *.py file in it at startup.
- The in-game "Import AI" button copies a chosen .py into Mods and reloads
  all mods without restarting. Reloading re-executes each mod file from the
  top, so module-level state is reset when that happens.
- A file that raises an error while loading, or has no callable choose_move,
  is skipped silently (no error message). Test the file before sending it.
- Loaded mods appear in: the Player vs AI difficulty menu and both AI vs AI
  menus (X and O must be different AIs).


3. THE `game` ARGUMENT
----------------------
choose_move receives a CLONE of the current UltimateBoard, so changing it
cannot corrupt the real game. It is the mod's turn: game.turn is the mod's
own symbol ("X" or "O"). X always moves first.

Attributes:
  game.cells         list of 9 lists of 9 strings. cells[board][cell] is
                     "", "X" or "O". Boards and cells are numbered 0-8,
                     row by row:   0 1 2
                                   3 4 5
                                   6 7 8
  game.small_status  list of 9 strings, one per small board:
                     "" (still open), "X" (won by X), "O" (won by O),
                     "D" (drawn / full with no winner).
  game.meta_status   "" while the game is running, else "X", "O" or "D".
  game.next_board    int 0-8 = the small board the mover must play in, or
                     None = the mover may play in any unfinished small board.
  game.turn          "X" or "O" - the side to move (this is you).
  game.last_move     (board, cell) of the previous move, or None.

Methods:
  game.legal_moves() -> list of (board, cell) tuples. Never empty while the
                        game is running.
  game.play(board, cell) -> bool. Applies a move (alternates turn, updates
                        small_status, meta_status and next_board). Returns
                        False and changes nothing if the move is illegal.
  game.clone() -> independent copy, for look-ahead search.
  UltimateBoard.winner(list_of_9_strings) -> "X", "O", "D" or "" for any
                        3x3 grid (static method, not needed by most mods).


4. RULES OF THE GAME (as implemented)
-------------------------------------
- 9 small boards form a 3x3 meta-board. Move (board, cell) puts your mark in
  that cell of that small board.
- The cell you pick decides the small board the opponent must play in next:
  cell c -> opponent plays in board c.
- If that target board is already won or drawn, the opponent may play in ANY
  unfinished small board (next_board is None).
- A small board is won with 3 in a row inside it. If it fills with no winner
  it is drawn ("D") and counts for nobody.
- The game is won by taking 3 small boards in a row on the meta-board.
  If all boards are finished with no meta line, it is a draw. Note: three
  drawn boards in a line also end the game as a draw.
- Winning or drawn small boards can no longer be played in.


5. RETURN VALUE RULES (important)
---------------------------------
- Return a TUPLE (board, cell) of two ints. A list such as [4, 4] will NOT
  match and is treated as illegal.
- The move must be in game.legal_moves().
- If choose_move raises an exception, returns an illegal move, or returns
  None, the game silently plays a RANDOM legal move instead. A bug therefore
  shows up as a weak, random-looking AI, not as an error.
- Never call game.play() on the game you were given expecting it to affect
  the real board; it is only a scratch copy.


6. PERFORMANCE / RUNTIME LIMITS
-------------------------------
- choose_move runs on the GUI thread. The window freezes while it thinks.
  Keep each move under about 1-2 seconds. Use a time budget with iterative
  deepening rather than a fixed deep search.
- No sandbox: the mod runs with full Python access. Users should only import
  mods they trust. Do not write to files or use the network.
- State kept in module-level variables (for example a transposition table)
  persists between moves in the same session, and is reset when mods reload.


7. RANKING POINTS
-----------------
- Mod AIs are gameplay-only. They never gain or lose RP, and beating a mod
  never awards the player RP or leaderboard entries. Only the six built-in
  AIs are ranked.


8. MINIMAL WORKING EXAMPLE  (save as Mods/greedy.py)
----------------------------------------------------
import random

AI_NAME = "Greedy"

def choose_move(game):
    me = game.turn
    legal = game.legal_moves()
    for board, cell in legal:               # take a small-board win if any
        t = game.clone()
        t.play(board, cell)
        if t.small_status[board] == me:
            return (board, cell)
    return random.choice(legal)


9. TESTING CHECKLIST FOR A NEW MOD
----------------------------------
1. The file imports and runs with no errors on plain Python 3.
2. choose_move(game) returns a tuple that is in game.legal_moves(), including:
   - the very first move of the game (81 legal moves, empty board),
   - a position with next_board = None,
   - a position with exactly one legal move.
3. It finishes within the time budget on a crowded mid-game position.
4. It plays as both "X" and "O" (never hard-code your symbol; use game.turn).
5. Play it against the built-in AIs (or itself, with random openings) to
   confirm it is not falling back to random moves.

A strong reference mod (bitboard alpha-beta, iterative deepening,
transposition table) is "cassandra.py" - use it as a template.
